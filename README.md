# Neon Snake

A polished, dependency-free canvas snake game in a single `index.html`.

- Dark page and canvas with a subtle grid
- Neon-green snake and pulsing magenta food
- Score tracking with persistent best score, speed that increases every bite
- Game-over screen with one-tap restart
- Controls: arrow keys / WASD, Space/Enter to start or restart, P to pause, swipe + D-pad on touch
- Respects `prefers-color-scheme` for the page chrome

Play it live: https://amleshwar19.github.io/neon-snake/
